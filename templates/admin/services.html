如何启动后台服务

后台服务启动方式（按部署环境选择其一，两者不要同时使用，否则定时任务会重复执行）：

  • 开发环境（Windows）：激活 .venv 后，分别启动 python manage.py runserver 0.0.0.0:8000、队列 celery -A pm worker -l info 与定时调度 celery -A pm beat -l info。
  • 生产环境（openEuler / Linux）：由 deploy.sh 自动配置——Web 服务 gunicorn 常驻 + 队列常驻进程（systemd 服务 pm-celery，即 celery -A pm worker）+ pm-celery-beat（celery -A pm beat）定时调度。

提示：本页的队列状态检测 celery worker 进程，定时任务状态检测 celery beat 进程，两者独立判断。
